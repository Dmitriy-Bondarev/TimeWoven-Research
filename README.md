# timewoven-research

Контентный сайт TimeWoven на Astro (TW-CONTENT-001).

**Домен (канон):** https://research.timewoven.ru

## MAC

```bash
npm install
npm run dev
npm run build
```

## Структура

- `src/content/` — articles, research, essays, authors
- `src/layouts/BaseLayout.astro` — canonical, SEO meta
- `public/robots.txt` — sitemap ссылка
